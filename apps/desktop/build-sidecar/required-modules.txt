# 少一个就让构建失败。
#
# 为什么需要这份清单：PyInstaller 靠静态分析决定收哪些模块，只在函数体里
# import 的东西它看不见，而且**不会报警**。实测漏掉过 jinja2 / tenacity / tqdm
# 三个 pyproject 里精确钉版本的核心依赖，漏了之后 `serve` 照样起来、照样绑端口，
# 用户点到那个功能才炸。
#
# 加新依赖时也往这里加一行；这份清单就是「什么算装齐了」的定义。
