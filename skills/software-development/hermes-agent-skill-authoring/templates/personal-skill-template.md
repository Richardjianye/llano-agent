# 发票助手

## 适用场景
- 同事上传发票，需要提取字段并核对时。
- 不适用：纸质发票还没扫描的情况，先让同事扫描。

## 前置条件
- 发票的图片或 PDF 已上传到会话。

## 步骤
1. 调用 `ocr_extract`，参数 `language=zh-CN`。
2. 校验 `invoice_code`、`invoice_number`、`amount`。
3. 金额不一致时，标记 `status=needs_review`。

## 注意事项
- 所有金额以人民币元为单位，保留两位小数。
- 不要编造缺失字段；缺失时返回 `null`。
- 示例值一律用占位符，如 `<发票号>`、`{客户名}`。

## 怎么验证
- 提取出的发票代码、号码、金额与原件逐项一致。
