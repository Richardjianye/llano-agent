# 工作台使用指南

回答同事「工作台怎么用」的问题。**先照下面的步骤直接回答。**这里没写到的，直说「这个我不确定」，请同事联系管理员——
不要去翻安装目录、源码，也不要探测网关接口；查不到就是查不到，不要为了「验证」跑一长串命令。

## When to Use

- 同事问：怎么登录、改密码、忘记密码、退出登录；怎么更新；怎么切换模型；技能怎么导入或分享；项目协作在哪；我做的文件放哪了；出了问题找谁。
- 同事发来一张截图问「下一步怎么做」：先看清截图停在哪个页面，直接回答下一步点哪里，别反问「你想怎么做」。
- 同事需要操作本机浏览器抓取登录后数据：先读取 `references/browser-data-workflow.md`，按专用配置、登录检查、少量验证、分批采集与验收的流程执行。
- 不适用：配置、扩展或编排工作台本身（管理员 / 开发者场景），那种用 `hermes-agent` 技能。

## 怎么答

- 先给结论，再一步一步说：在哪个页面、点哪里、点完会看到什么。一次只说一步，别甩术语。
- 语气温和，别让同事觉得这个问题问得简单。同事卡住了先安慰一句，再带着走。
- 不要让同事把密码发给你，也不要代为登录；需要输密码的地方，请同事自己输。

## 常见问题

### 怎么让工作台操作浏览器抓数据？

先读 `references/browser-data-workflow.md`。优先使用同事电脑上的 Edge 等浏览器，在**独立的用户数据目录**创建专用配置，保留以后复用；不要在日常默认配置开启远程调试，不要为连接调试关闭同事普通浏览器或复制默认配置的 Cookie。Edge 可能通过正常账号同步或站点单点登录恢复部分登录态，先打开目标站点确认；没登录就请同事在专用窗口正常登录。CDP 连接不合适时使用 Playwright 后备流程，遇验证码交由同事处理。

### 登录密码怎么改？

工作台客户端里没有改密码的入口。登录密码是公司 AI 网关账号的密码，要在网关控制台的网页里改：

1. 用浏览器打开公司 AI 网关的登录页（就是客户端登录时连接的那个网关，一般是 https://gateway.example.invalid；打不开就问管理员最新地址）。
2. 用自己的账号登录。
3. 点右上角自己的头像或姓名，选「修改密码」。
4. 填「当前密码」「新密码」（至少 8 位）「确认新密码」，点「确认修改」。
5. 改完后，其它设备上的登录会失效，客户端需要重新登录一次。

「同时吊销我的全部 API Key」这一项，只有怀疑密码或密钥泄露时才勾。

### 初始密码在哪？忘记密码怎么办？

账号是管理员建的，初始密码在建账号时由系统随机生成、只显示一次，由管理员当面或私信转告。忘了或丢了，请管理员在网关后台重置——
新密码随机生成、只显示一次，拿到后尽快按上面的步骤自己改掉。自己没法找回。

### 怎么退出登录？

「设置 → 关于」里点「退出登录」。

### 怎么更新客户端？

客户端会在后台自动检查更新，有新版本会通知你。想手动查：「设置 → 关于」点「立即检查」，有更新就点「立即更新」。
更新期间不要自己重新打开客户端，更新器完成后会自动重新打开。

### 怎么切换模型？

在聊天输入框旁边点模型名称，选想用的模型，新的对话就用它。能看到哪些模型由管理员开通；看不到想用的，找管理员。

### 技能怎么导入、分享？

- 导入一个别人给你的技能：打开侧栏「技能与工具」，切到「技能」页签，点「＋ 添加技能」，选文件夹、.zip 压缩包或单个 SKILL.md 文件。
  添加前会先做安全检查，缺中文名称或简介时自动补上，不用自己填；添加后马上出现在列表里，只在你自己的电脑上可用，新开的对话里生效。
- 想让同事也能用：在「技能」页签里点开这个技能，点「整理并发布」。会先做机器检查（安全、格式、个人信息、发布标识），
  再用 AI 整理成规范格式给你对照审阅；检查出的个人信息要逐条替换或确认保留后才能发。技能已经符合规范时会跳过 AI 整理。
  发到你所在部门的技能空间；要让全公司都能装，请部门主管在网关后台晋级。查看范围扩大不意味着可以修改、下架或晋级其他部门的技能，写入操作仍按原有管理权限执行。
- 想装别人发布的技能：打开侧栏「技能与工具」，默认就是「浏览技能中心」，搜索后安装。经理及以上、管理部门全员、技术部门可查看全部已上架技能；其他同事能查看公司空间、本部门及上级部门空间内有权限的技能。
- 想固化一个自己的工作流程：直接告诉我，我帮你做成技能，并起一个中文名。

### 项目协作在哪？

侧栏「消息平台」下方的「项目协作」，里面有项目群聊、成员和任务。这个功能还在完善，遇到问题请找管理员。

### 我做的文件放哪了？

默认放在桌面上的「LLANO Agent 文件」文件夹里，按用途分了子文件夹。我交付文件时会直接告诉你路径。

### 出了问题找谁？

登录、账号、密码、模型开通、更新失败这类问题，都找管理员。把出错那一屏的截图和你刚做的上一步一起发过去，会快很多。
